# 💅 Лендинг для мастера маникюра «Ноготки принцессы»

Адаптивный одностраничный сайт для мастера ногтевого сервиса.  
Вёрстка на чистом HTML/CSS/JS, без фреймворков и библиотек.  
Подходит для портфолио или быстрого старта под реального заказчика.

---

## ✨ Особенности

- 🎨 **Тёмная тема** — переключается кнопкой, сохраняется в localStorage
- 📱 **Адаптив** — мобильные, планшеты, десктопы
- 🍔 **Бургер-меню** — fullscreen с плавной анимацией
- 🖼 **Lightbox** — клик по фото портфолио открывает увеличенное изображение
- ❓ **Аккордеон FAQ** — раскрывающиеся блоки с ответами
- 🎛 **Кастомный селект** — стилизованный выпадающий список для выбора услуги
- 📞 **Маска телефона** — автоматическое форматирование при вводе
- ✅ **Валидация формы** — имя, телефон, выбор услуги
- 🔗 **Кнопки «Записаться»** — скроллят к форме и подставляют выбранную услугу
- 🍪 **Cookie-уведомление** — с сохранением согласия
- 🔒 **Политика конфиденциальности** — модальное окно
- 🧹 **Чистый код** — семантическая вёрстка, БЭМ-именование классов

---

## 🛠 Технологии

| Технология | Для чего |
|------------|----------|
| HTML5 | Семантическая разметка |
| CSS3 | Flexbox, Grid, CSS-переменные, медиазапросы, backdrop-filter |
| JavaScript | Все интерактивы (бургер, lightbox, аккордеон, кастомный селект, маска) |
| Google Fonts | Шрифты Playfair Display + Inter |
| LocalStorage | Сохранение темы и cookie |
