# 💅 Лендинг для мастера маникюра «Ноготки принцессы»

Адаптивный одностраничный сайт для мастера ногтевого сервиса.  
Вёрстка на чистом HTML/CSS/JS, без фреймворков и библиотек.  
Подходит для портфолио или быстрого старта под реального заказчика.

🔗 **Демо:** *[вставить ссылку на GitHub Pages]*  
📁 **Код:** `git clone https://github.com/ваш-логин/nails-landing.git`

---

## ✨ Особенности

- 🎨 **Тёмная тема** — переключается кнопкой, сохраняется в localStorage
- 📱 **Адаптив** — мобильные, планшеты, десктопы
- 🍔 **Бургер-меню** — fullscreen с плавной анимацией
- 🖼 **Lightbox** — клик по фото портфолио открывает увеличенное изображение
- ❓ **Аккордеон FAQ** — раскрывающиеся блоки с ответами
- 🎛 **Кастомный селект** — стилизованный выпадающий список для выбора услуги
- 📞 **Маска телефона** — автоматическое форматирование при вводе
- ✅ **Валидация формы** — имя, телефон, выбор услуги
- 🔗 **Кнопки «Записаться»** — скроллят к форме и подставляют выбранную услугу
- 🍪 **Cookie-уведомление** — с сохранением согласия
- 🔒 **Политика конфиденциальности** — модальное окно
- 🧹 **Чистый код** — семантическая вёрстка, БЭМ-именование классов

## 🛠 Технологии

| Технология | Для чего |
|------------|----------|

## 🚀 Запуск локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/nails-landing.git

2. Перейдите в папку проекта:
   ```bash
   cd nails-landing

3. Откройте index.html в любом браузере.
Для работы всех функций (включая форму) интернет-соединение не требуется, кроме загрузки шрифтов Google.

⚙️ Быстрая кастомизация под другого мастера
Что поменять	Где
Логотип	.header__logo (заменить текст)
Фото мастера	images/tatiana.png
Фото портфолио	images/nail-*.png
Аватары отзывов	images/comment-*.png
Фон Hero	images/front-img.jpg
Текст «О мастере»	Секция #about
Услуги и цены	Секция #services
Номер телефона	href="tel:+79999999999" и текст
Карта	Заменить src в iframe
Соцсети	Ссылки в #contacts и mobile-menu__social
📬 Форма заявки
В демо-версии форма не отправляет данные на сервер — только имитация с alert.
Для реального использования подключите Formspree (бесплатно):

Зарегистрируйтесь на formspree.io

Получите свой ID формы

В index.html добавьте в <form>:

action="https://formspree.io/f/ваш_ид"
method="POST"
